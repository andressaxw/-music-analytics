# 🎵 Music Analytics

Projeto desenvolvido em linguagem C para analisar e organizar dados de reproduções musicais.

## 📌 Sobre o projeto

O Music Analytics é um programa que simula a análise de audiência de 10 músicas, exibindo suas quantidades de reproduções e organizando os resultados em ordem crescente e decrescente.

## ⚙️ Funcionalidades

- Exibição da audiência original.
- Ranking de músicas em ordem crescente.
- Ranking de músicas em ordem decrescente.
- Preservação dos nomes das músicas durante a ordenação.

## 💻 Tecnologias utilizadas

- Linguagem C
- Visual Studio Code
- GCC (compilador C)

## 📚 Conceitos praticados

- Arrays
- Estruturas (`struct`)
- Condicionais (`if`)
- Laços de repetição (`for`)
- Funções
- Algoritmo Bubble Sort

## ▶️ Como executar

Compile o programa:

```bash
gcc main.c -o music
```

Execute no Windows:

```powershell
.\music.exe
```
