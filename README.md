## 📌 Sobre o projeto

O **Music Analytics** é um projeto desenvolvido em linguagem C que simula a análise de audiência musical.

O sistema utiliza dados fictícios de 10 músicas para organizar e apresentar suas quantidades de reproduções, criando rankings em ordem crescente e decrescente.

## ⚙️ Funcionalidades

- Exibição da audiência original das músicas.
- Ranking de músicas com menor quantidade de reproduções.
- Ranking de músicas com maior quantidade de reproduções.
- Ordenação automática dos dados.
- Preservação dos nomes das músicas durante a ordenação.

## 📊 Demonstração

O programa apresenta três resultados principais:

1. **Audiência original:** exibe as 10 músicas e suas reproduções.
2. **Ranking crescente:** organiza as músicas da menor para a maior audiência.
3. **Ranking decrescente:** organiza as músicas da maior para a menor audiência.

### Exemplo de ranking decrescente

| Posição | Música | Reproduções |
|---|---|---:|
| 1º | Música 7 | 5100 |
| 2º | Música 4 | 4500 |
| 3º | Música 9 | 3900 |
| 4º | Música 5 | 3200 |
| 5º | Música 8 | 2700 |
